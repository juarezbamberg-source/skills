Fornecer os requisitos curriculares oficiais da UC10 do Técnico em Informática (Senac) — indicadores, conhecimentos, habilidades e atitudes/valores — extraídos do Plano de Curso. ## CAMADA 2 — IDENTIFICAÇÃO E CONTEÚDO OFICIAL
UC10: Desenvolver banco de dados. Carga horária: 72h → 24 aulas de 3h. Qualificação: Assistente de Desenvolvimento de Aplicativos Computacionais (UC9–UC13). Pré-requisito: UC9 (Desenvolver Algoritmos).

### Indicadores (eixos de avaliação)
1. Constrói diagramas de dados aferindo a modelagem e estrutura do banco de dados, de acordo com as especificações técnicas.
2. Realiza a instalação e configuração de sistema gerenciador de banco de dados (SGBD), de acordo com especificações técnicas.
3. Elabora scripts SQL de construção, inserção e manipulação dos dados conforme especificação técnica da linguagem SQL.
4. Realiza importação e exportação de dados, conforme regras do sistema gerenciador de banco de dados (SGBD).
5. Planeja rotinas de backup e restore da base de dados, conforme especificações técnicas do sistema gerenciador de banco de dados (SGBD).

### Conhecimentos
- Modelagem conceitual do banco de dados: levantamento de dados e especificação de requisitos. Dicionário de dados. Integridade referencial. Arquitetura de arquivos de dados. Teoria dos conjuntos. Tipos de dados. Normalização. Modelo de entidade e relacionamento: entidade, visão, atributos, índices, chave candidata, chave primária e estrangeira, relacionamentos e integridade referencial.
- Modelagem física de banco de dados relacional: linguagem SQL — histórico, definições e aplicabilidade. Ferramentas de modelagem e manutenção. Criação, manipulação, ordenação, listagens e operações em consultas SQL. Subconsultas SQL. Datas. União, intersecção e junção de dados. Entidade, views, atributos, índices, chave candidata, chave primária, chave estrangeira, relacionamentos e integridade referencial. Importação e exportação de dados.
- Segurança do banco de dados: normas. Segurança da informação em banco de dados: redundância, concorrência, integridade e consistência. Criptografia. Autenticação. Falhas. Ameaças. Controle de acesso. Backup e restore.

### Habilidades
Modelar estrutura de banco de dados. Organizar arquivos. Criar a documentação do projeto. Utilizar termos técnicos nas rotinas de trabalho.

### Atitudes/Valores
Cordialidade no trato com as pessoas. Sigilo no tratamento de dados e informações. Proatividade na resolução de problemas. Flexibilidade nas diversas situações de trabalho.

## CAMADA 3 — REGRAS DE APLICAÇÃO NO PLANEJAMENTO
- Toda aula prática deve rastrear ao menos 1 indicador; toda avaliação deve declarar quais indicadores cobre (avaliação por menções A/PA/NA).
- Conhecimentos → parte teórica (~40% da aula); Habilidades → práticas (~60%); Atitudes/Valores → checklist formativo contínuo.
- A progressão dos indicadores 1→5 já sugere o desenho do módulo: modelar (diagrama de dados) → instalar/configurar o SGBD → escrever scripts SQL (DDL/DML) → importar/exportar massas de dados → planejar backup e restore. Usar como espinha dorsal.
- Ordem didática recomendada dentro de modelagem: requisitos/dicionário de dados → MER (entidade/relacionamento, chaves) → normalização → modelagem física → SQL. Não pular normalização: é ela que sustenta o indicador 1.
- Metodologia sugerida (Plano de Curso, orientações metodológicas): debates, análises de conceitos e produção de conteúdo; prática de manipulação de dados com estudos de modelagem e gerenciamento; administração de objetos de banco com SQL Plus e SQL Developer; inserts, updates e delete; uso de DML e DDL; criação e execução de rotinas de importação de massas de dados; trabalho prioritariamente em laboratório de informática.
- Ferramentas do plano: SQL Plus e SQL Developer (Oracle) — citados explicitamente. SGBD alternativo (PostgreSQL/MySQL/SQLite) exige justificar equivalência; DML/DDL são o contrato, não a ferramenta.
- Segurança do banco de dados conecta-se à UC5 (segurança de redes: PSI, controle de acesso) — reaproveitar analogias de controle de acesso e backup; na UC10 o foco é o dado (concorrência, consistência, integridade).
- Fronteira com as UCs seguintes: UC10 = persistência; UC12/UC13 consomem o banco via CRUD (classes/métodos → SQL). O Projeto Integrador da qualificação articula UC10, 11 e 12 (o plano lista tecnologia transversal para esse projeto).
